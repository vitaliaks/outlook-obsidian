Privacy

Outlook to Obsidian does not collect email content or transmit email content to the developer or any server. It uses no analytics, telemetry, or cookies.

All email processing and Markdown generation happen locally inside the Outlook add-in. The generated note is placed in the system clipboard, temporarily replacing its previous contents. Obsidian reads the note locally through the supported clipboard=true URI parameter.

The add-in invokes the locally registered obsidian:// protocol directly from the Outlook task pane. It does not send the note or its destination through an intermediate web page.

The add-in stores only the user-entered Obsidian vault name and target folder in the task pane’s local browser storage. Email content and Outlook metadata are never stored there. Settings can be removed with the Reset button.

GitHub Pages only serves the add-in’s static HTML, CSS, JavaScript, and image files. Microsoft’s official Office.js CDN serves Office.js; email content is not sent to that CDN by this add-in.
