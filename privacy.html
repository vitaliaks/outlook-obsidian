Privacy

Outlook to Obsidian does not collect email content or transmit email content to the developer or any server. It uses no analytics, telemetry, cookies, or browser storage.

All email processing and Markdown generation happen locally inside the Outlook add-in. The result is passed directly to the locally installed Obsidian application through an obsidian:// URI.

No user data is stored by the add-in. GitHub Pages only serves the add-in’s static HTML, CSS, JavaScript, and image files. Microsoft’s official Office.js CDN serves Office.js; email content is not sent to that CDN by this add-in.
